# SAP server and module page redesign

## Goal
Apply one premium, consistent ServerFY design across every SAP server and module detail page, from the top section through FAQs, without changing existing content, URLs, SEO, navigation, footer, or backend behavior.

## Visual direction
- Use the selected **Enterprise Modern Pro** direction: deep navy infrastructure surfaces, crisp white content areas, controlled orange highlights, and clear enterprise typography.
- Keep pages fast with CSS and inline SVG-style graphics rather than large decorative images.
- Use full-width alternating bands, stronger headings, cleaner information hierarchy, and restrained glass/neumorphic depth.

## Implementation
1. Upgrade the shared server-page top section with breadcrumbs, orange category label, improved title/description hierarchy, useful actions, trust signals, and a lightweight technical visual.
2. Upgrade the SAP module top section to the same system while preserving module-specific content and actions.
3. Replace the empty SAP Easy Access panel with a compact data-flow learning graphic that adapts to each module and works on mobile.
4. Restyle shared lower sections: benefits, specifications, checklists, process flows, transaction tables, comparisons, audiences, scenarios, pricing, and FAQs.
5. Apply the shared redesign to dedicated-server pages without removing their specialised content or comparison sections.
6. Keep orange icons prominent, avoid nested cards, preserve accessible contrast, and respect reduced-motion settings.

## Validation
- Check representative ECC server, dedicated server, and SAP MM module pages at mobile, tablet, and desktop widths.
- Confirm no horizontal overflow, clipped text, overlapping controls, console errors, or broken links.
- Confirm metadata and current SEO-friendly URLs remain unchanged.

## Scope note
This is frontend-only. No files in the separate backend repository will be changed.
